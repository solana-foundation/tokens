## Scopes

Every v1 endpoint accepts the umbrella scope **`assets:read`**, which is on every key by default. Four fine-grained scopes exist for keys that should only read one kind of data:

| Scope                  | Grants                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| `assets:read`          | Everything on this surface.                                                                  |
| `assets:profile:read`  | `include=profile` on asset detail.                                                           |
| `assets:risk:read`     | `include=risk` on asset detail and `GET /v1/assets/risk-summary`.                            |
| `assets:ohlcv:read`    | `include=ohlcv` on asset detail.                                                             |
| `assets:markets:read`  | `include=markets` on asset detail.                                                           |

A request that asks for an include the key cannot read returns `403` with `details.required` and `details.granted`.

v2 execution endpoints require `execution:read`, which is granted to all keys by default.

## Example client

```ts
interface ApiErrorEnvelope {
  error: { _tag: string; message: string; details?: Record<string, unknown> };
}

function isApiError(value: unknown): value is ApiErrorEnvelope {
  const error = (value as { error?: { _tag?: unknown; message?: unknown } } | null)?.error;
  return typeof error?._tag === "string" && typeof error.message === "string";
}

export async function getJson<T>(path: string, apiKey: string): Promise<T> {
  const res = await fetch(`https://api.tokens.xyz${path}`, {
    headers: { "x-api-key": apiKey },
  });
  const json: unknown = await res.json().catch(() => null);
  if (!res.ok) {
    if (isApiError(json)) throw new Error(`${json.error._tag}: ${json.error.message}`);
    throw new Error(`HTTP ${res.status}`);
  }
  return json as T;
}
```
